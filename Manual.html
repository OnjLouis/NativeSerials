Purpose

Native Serials is a local, read-only Native Instruments inventory reporter. It scans Native Access, RAS3 activation token, installed product, and Service Center metadata already present on the computer, then shows an accessible list of products and recovered serial numbers.

The app is designed for screen reader users. The product table is a standard control, serials are hidden by default, and common actions are available from menus and keyboard shortcuts.

Requirements and Installation

Windows: 64-bit Windows with .NET Framework 4.8. Extract the Windows ZIP into a writable folder and open NativeSerials.exe. Keep the supplied DLL, manual and notices alongside it. No installer or administrator access is needed for normal use.

Mac: macOS 13 or later, on Apple Silicon or Intel. Extract the Mac ZIP and move Native Serials.app to the main Applications folder. The app is Developer ID signed and notarized.

Native Instruments product metadata must already be present on this computer. Native Serials does not sign in to Native Access, register products or download missing libraries. Connect drives containing your libraries before measuring storage.

Important Limitations

Native Serials is neither endorsed nor supported by Native Instruments. Native Instruments, Native Access, Kontakt, Komplete Kontrol, Maschine, and related product names belong to Native Instruments and their respective owners.

Native Serials may not find every product serial you own. It can only report information available in local files that it understands. Some products may use metadata formats not currently handled, may be registered but not installed, may be attached to a bundle rather than an individual product row, or may require online account information that this app does not access.

If a product appears without a serial, or a serial appears only after Native Access has been run, that usually means the local metadata has not provided enough information yet. This does not mean the product is unlicensed.

Privacy

Native Serials works locally. It does not send product names, serials, paths, or token contents to any server.

RAS3 JWT files can contain serial claims. Native Serials decodes those files locally and masks serials in the main table until Reveal serials is checked. Use export with care, because the HTML report can include revealed serial numbers when that option is enabled.

Main Window

The main window has two tabs: Inventory and Storage by Company. Inventory contains a search box, a Rescan button, the Reveal serials checkbox, the Products shown radio group, Save HTML Report and a product table. The app starts in Inventory with keyboard focus in the products table.

Storage by Company

Select the Storage by Company tab, choose View, Storage by Company, or press Ctrl+2 on Windows or Command+2 on Mac. This tab scans registered content and installation locations in the background. It also looks for matching product plug-ins, standalone applications and support data in standard installation locations, using product names and publisher information. Plug-ins and applications are not loaded or run during scanning.

The Companies table lists each company, its registered product count, measured total size, and how many products were fully measured. Rank companies by largest total, most products, or name. Select a company to populate the Products table, then choose largest first, smallest first, or product name. The filter searches product names and folder locations. The company total below the table always includes all that company's products, not just filtered rows.

Totals and completed scan figures appear on separate lines for easier reading. Both tabs belong to the same application window. Select Inventory with Ctrl+1 on Windows or Command+1 on Mac. Escape from Storage also returns to Inventory. Switching tabs keeps the last completed results and does not close the application.

Storage totals and Scan status are selectable, read-only text areas. Read them line by line with the arrow keys, or select text and use the normal copy shortcut. Tab and Shift+Tab leave these areas normally.

Tab and Shift+Tab move between controls and the tab selector. With focus on the selector, Left and Right select a tab without moving into its contents. Press Tab to enter that tab's controls.

Scan refreshes sizes; Cancel stops the scan without replacing the last completed results. Scanning starts when Storage is first selected, not when the app opens. Results update at completion and do not continually rebuild the focused table. Disconnecting a drive produces unavailable or partial results; reconnect it and scan again.

Unavailable means no known product location could be accessed; it is not a zero-byte installation. No location means no location was registered or matched. Partial means some known locations or entries could not be read, even if others were counted. Links skipped means nested symbolic links or Windows junctions were not followed. A link used as the registered root is resolved, but nested links are skipped to avoid loops and unrelated content. Entire filesystem roots, shared plug-in roots and other unsafe broad locations are not counted as product installations.

Sizes use MiB and GiB (binary units) and are logical file sizes, not allocated or reclaimable disk space. Shared and nested registered folders count once per company and once in the overall total. Individual product rows may overlap, and different company totals can overlap if they share content. Hard links count under each filename. A changing folder is a snapshot, not a locked backup. Known Fracture Sounds Blueprint and Native Instruments company-label variants are grouped together; original metadata is not changed.

The Location column lists all counted paths, including separate plug-in formats and applications where matched. Coverage includes registered locations and verified matches, not a whole-drive search or a complete uninstall estimate. Unregistered files in nonstandard locations, unmatched names, shared manufacturer data and files without enough publisher information may remain uncounted. Measured means the selected locations were readable, not that every file belonging to a product has been found. Missing company metadata appears as Unknown company; the app does not assign a company from a folder name. Counts are registered products, not proof of purchases or complete ownership.

When an NKS folder sits inside a library with a matching product name, its enclosing library is included. On Mac, discovery also checks known manufacturer folders on locally mounted volumes, UAD resource packages and Waves component metadata and sample-library folders. It does not search network volumes or unrelated folders for possible matches.

Ctrl+O on Windows or Command+O on Mac opens the selected product's primary folder. For a plug-in file or application bundle, it reveals the item in its containing folder instead of launching it. Use the copy shortcut to copy selected table rows, including their counted locations. Use the save shortcut to export all scanned companies to HTML, with a named table for each company. Storage exports never include serials, even when inventory serials are revealed, but they do include product names and folder paths. Review a report before sharing it.

Exporting and Copying

Select one product in either tab and open its context menu or the Actions menu to open detected content, support, application, VST2, VST3, AU or AAX folders. Every opening command includes the word Folder. Only matching locations available on this computer are offered. Multiple locations of one type appear in a submenu. Where a specific plug-in, file or application bundle is known, Finder or Explorer selects that item. Otherwise the folder opens normally. These commands never run a plug-in or application. Additional locations are discovered in the background; if a menu is opened immediately after a rescan, reopen it once discovery has finished.

Use the copy command or shortcut to copy selected products as tab-separated text. Each table also has a context menu with Copy Selected Rows. Multiple selected inventory rows are copied together. The inventory copy menu respects Reveal serials; storage copies never include serial numbers.

Use File, Save HTML Report on Windows or Native Serials, Save HTML Report on Mac to create a readable HTML report from the current filtered table. If Reveal serials is off, serials are masked in the report. If Reveal serials is on, full serials are included.

Updates and Support

Use Help, Check for Updates on Windows, Native Serials, Check for Updates on Mac, or Shift+F1 to check GitHub releases. Use Help, Version History to review release notes. Use Help, Project Page on GitHub or Ctrl+F1 on Windows and Command+F1 on Mac to open the project page.

Version 1.1 and later verify a signed file manifest and the download's SHA-256 before replacing program files. Mac updates also verify the app's Developer ID, notarization and both supported architectures. Missing or invalid signatures stop installation. The previous program is kept until replacement succeeds, and a failed replacement attempts to restore it. Product registrations and sample libraries are not changed. Leave the app in a writable location and allow it to close and reopen during installation.

Upgrading from Mac version 1.0: quit Native Serials, download the Mac ZIP from the releases page, and replace the app in Applications manually. Do not use version 1.0's Install command for this upgrade: its older installer does not preserve the new app's signing identity. Subsequent updates can use the verified in-app installer.

Upgrading from Windows version 1.1: quit the app and extract the latest Windows ZIP over your existing program files. Version 1.1 has a connection problem in its update installer; 1.1.1 fixes it. Other files in your program folder can stay in place.

If an update fails, its message explains whether the old program was restored. On Windows, recent updater diagnostics are in %LOCALAPPDATA%\NativeSerials\Updates\LastUpdate.log. On Mac, a failed installation records ~/Library/Application Support/Native Serials/LastUpdate.log. These logs concern installation, not your product serials. Keep any recovery files identified in an error until the problem is resolved.

Use Help, Contact for feedback and Help, Donate if you want to support continued development.

Help, Diagnostics opens read-only diagnostic information for the active tab. Use Alt+F1 on Windows or Option+F1 on Mac. Diagnostics do not reveal serial numbers.

Press F1 for help about the focused control. Focus moves directly to read-only text; use the arrow keys to read it. Detailed explanations appear here rather than being repeated whenever you focus a control. If no control-specific explanation is available, window help is shown. Each help dialog includes Open Manual for the full guide. Press Escape or activate Close to dismiss help and return to the previous control. The Help menu also has an independent Open Manual command.

In a report window, Copy All copies the complete report. To copy only an excerpt, select text and press Ctrl+C on Windows or Command+C on Mac.
